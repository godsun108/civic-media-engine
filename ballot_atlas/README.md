# Ballot Atlas v0.1

Local-first candidate record change detector. Downloadable complete runnable package is provided in the ChatGPT conversation. This directory begins the Civic Media Engine integration. Requires official-source normalized candidate data; no live ingestion, verified ballots, or AI-generated policy positions yet. Run `python ballot_atlas/engine.py` after adding sourced records to incoming.json. FEC OpenFEC and Congress.gov API adapters are next; state and county election sources require jurisdiction-specific connectors. No ranking or endorsement.
