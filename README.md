# Civic Media Engine (CME)

A global, multi-outlet media operating system for reporting, education, entertainment, and transparent commerce.

## Architecture
CME is independent from [VHE](https://github.com/godsun108/virtual-human-engine) (virtual talent) and [Civic Ledger](https://github.com/godsun108/civic-ledger) (public-record evidence). Systems exchange versioned content contracts, not internal database access.

## Editorial workflow
Source → evidence packet → research → classification (news / analysis / opinion / advocacy / sponsored) → production → verification → disclosure → approval → publishing → correction/analytics.

## Principles
Maintain source provenance, disclose synthetic hosts and material sponsorship, distinguish fact from interpretation, localize presentation without altering underlying facts, and retain corrections and release history. Political/public-policy publication requires jurisdiction-aware human compliance review.

## Initial milestone
Implement source/story/outlet registries, persistent audit logs, editorial approvals, and one working web outlet before adding publishing adapters or monetization.
